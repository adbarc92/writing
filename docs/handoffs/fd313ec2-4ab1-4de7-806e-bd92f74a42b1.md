## Live decisions and constraints not visible in the code

1. **`base` stays `"/"`.** Astro's `base` applies site-wide; setting it to `/writing` would move the
   treatise too. The prefix comes from the `src/pages/writing/` directory. This is already
   commented in `astro.config.mjs` — do not "fix" it.
2. **`/writing/*` URLs are frozen.** They carry canonical tags, OG tags, the feed, a link recorded
   in `claims.yaml`, and a link the user is about to post to LinkedIn. Slug rules are pinned by
   tests in `src/lib/slugs.test.mjs` against the real filenames.
3. **Dates must be formatted in UTC.** `z.coerce.date()` parses `2026-08-10` to UTC midnight;
   formatting in local time renders the previous day anywhere west of Greenwich. The writing repo's
   `src/lib/dates.ts` exists for exactly this and its logic must be carried into Phase 3.
4. **CI in `portfolio-treatise` has never worked — 8 runs, 8 failures**, all with zero steps
   executed, including runs predating this session. Every real deploy has been manual via
   `npm run deploy` (`scripts/deploy-local.mjs`), which runs the same gates then pushes to the
   publish repo. Evidence: every deploy commit in `adbarc92.github.io` carries the local script's
   message format; the CI format appears nowhere. Cause is probably exhausted Actions minutes on a
   private repo — unconfirmed, the billing API needs a `user` scope the local token lacks. **Do not
   assume a merge deploys anything.**
5. **The merged repo must be public** (design decision). That would also fix #4, since public repos
   do not consume the Actions quota. Flipping visibility is the user's call and has not been done.
6. **The content gate scopes its two lists differently** since Phase 1, and this is deliberate:
   retracted claims scan all emitted text, banned vocabulary scans reader-facing output only.
   Registering React made the gate fail on `case"seamless":` inside React's attribute table. If a
   vendor bundle trips the gate again, scope is the fix — never deleting a term.
7. **`npm test` must not glob `scripts/` bare.** `node --test scripts/` executes
   `deploy-local.mjs`, which deploys. The script targets `*.test.mjs` explicitly for that reason.
8. **Two documented gates do not exist.** `AGENT-PROMPT.md` lists four CI gates; only the content
   gate and its canary are built. The link gate and the rendered-page claims gate were specified
   and never written. Consolidation cannot inherit link-checking; building them is follow-on work
   and explicitly out of scope for the migration.
